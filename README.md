# MySQL Assignment 2: Querying Data

SQL queries written against an employee database with three related tables
(`employees`, `departments`, `location`), built with primary and foreign key constraints.

## Topics covered
- DISTINCT, aliases (AS), WHERE with operators
- Filling missing values with UPDATE
- ORDER BY and LIMIT
- Aggregate functions: SUM, MIN, MAX, AVG
- GROUP BY and HAVING
- INNER, LEFT and RIGHT joins

## Setup
1. Run the schema script to create the database and tables.
2. Insert the sample data (departments and locations first, then employees).
3. Run the queries in `queries.sql`.

## Tools
MySQL, MySQL Workbench
